# 📱 AppSupabaseIT_2026_3

¡Bienvenido al repositorio de mi proyecto de Android! Esta es una aplicación desarrollada en **Kotlin** utilizando **Android Studio**, diseñada para gestionar y consultar información conectada a una base de datos en la nube mediante **Supabase**.

## 🚀 Características del Proyecto

*   **Desarrollo en Kotlin:** Uso de las últimas prácticas recomendadas de Android.
*   **Conexión con Supabase:** Integración del cliente de Supabase para la gestión de datos en tiempo real.
*   **Consulta de Alumnos:** Implementación de funciones (como `consultarAlumnos`) para obtener listados desde la base de datos.
*   **Interfaz Moderna:** Uso de `EdgeToEdge` para aprovechar toda la pantalla y diseño adaptable.
